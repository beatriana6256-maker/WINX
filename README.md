# WINX

Site inspirado no desenho **O Clube das Winx**, criado para apresentar as personagens, suas transformações e o universo da série.

## Sobre o projeto

O projeto foi desenvolvido usando apenas HTML. Ele reúne páginas dedicadas às Winx, à escola Alfea e a algumas das principais transformações da série.

## Conteúdo

- Página inicial do Clube das Winx;
- Página sobre a escola Alfea;
- Páginas de Bloom, Stella, Flora, Musa, Tecna e Aisha;
- Transformações Enchantix, Harmonix, Bloomix e Butterflix;
- Quiz sobre as Winx;
- Imagens, músicas e vídeos.

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `winx.html` em um navegador.
